# 口碑製造所 · WoM Factory 官方網站

真人寫真實口碑，被網友看見、被 AI 推薦。

## 部署

部署在 [Cloudflare Pages](https://pages.cloudflare.com/)，連線到此 repo 自動部署。

## 結構

```
/
├── index.html          一頁式網站主檔
├── sitemap.xml         搜尋引擎用 sitemap
├── robots.txt          爬蟲規則
├── llms.txt            AI 引擎用網站地圖
└── assets/
    └── cases/          案例截圖（去識別化版本）
```
